## Known traps

Rule ids taken from review-lessons.json (status active, case-insensitive, `scope` under `workflow/`): phase-output-not-committed-before-reap, envelope-shas-die-on-rebase-verify-by-content, conductor-manufactured-premise-downstream-of-correct-artifact, reviewer-git-stash-near-miss-shared-stack, ledger-write-verify-by-id-set-difference, a-safeguard-carries-its-own-ambiguity, git-status-cannot-prove-an-agent-wrote-nothing, an-enumeration-reads-like-a-measurement, device-free-space-is-the-fastest-moving-fact, a-chain-verified-within-one-layer-proves-nothing-about-reachability.

- **phase-output-not-committed-before-reap** (workflow/phase-contract, NEARS-1748) — a phase that PRODUCES FILES must end by committing them; the [11] reaper takes anything uncommitted and `git worktree prune --keep` has already failed cross-session; check `git status --porcelain` in the worktree at the END of every file-producing phase, not at merge time. (docs/workflow/review-lessons.json)
- **envelope-shas-die-on-rebase-verify-by-content** (workflow/merge-forensics, NEARS-1748/1749) — a rebase gives every commit a new identity while the old shas survive as dangling objects that still resolve; transfer a QA PASS or review verdict by CONTENT (blob hash of the merged file vs the tested revision), never by sha equality; when a reviewed sha moves, filter the delta to non-comment non-blank lines AND re-run the tests at the new tip anyway; record the MERGE COMMIT at [11]. (docs/workflow/review-lessons.json)
- **conductor-manufactured-premise-downstream-of-correct-artifact** (workflow/phase-packets, NEARS-1749) — a packet must not assert behaviour the conductor did not read at the implementing line; correct counts fused into a wrong composition sent two reviewers to disprove a phantom; before shipping a packet ask "which line makes this true?" and paste it. (docs/workflow/review-lessons.json)
- **reviewer-git-stash-near-miss-shared-stack** (workflow/git-safety) — the stash stack is REPO-GLOBAL while working-tree changes are per-worktree; a concurrent `git stash pop` pulls a stranger's churn in; the safe substitute for a clean tree is a throwaway `git worktree add`, never a stash. (docs/workflow/review-lessons.json)
- **ledger-write-verify-by-id-set-difference** (workflow/ledger-hygiene) — every write to `docs/workflow/review-lessons.json` is verified by set(ids at HEAD) − set(ids in working) == EMPTY and len(rules) == len(set(ids)), never by a rule COUNT; the file is routinely foreign-dirty, so a pre-edit snapshot diff is weaker and does not replace it. (docs/workflow/review-lessons.json)
- **a-safeguard-carries-its-own-ambiguity** (workflow/verification-design, NEARS-1749) — a check added to remove an ambiguity inherits all the trust of the check it guards; a control whose false-negative is indistinguishable from the fault inverts the discrimination; "ASSERTIONS SHOULD BE TIGHT, CONTROLS SHOULD BE LOOSE" — make a control as coarse as the discrimination allows. (docs/workflow/review-lessons.json)
- **git-status-cannot-prove-an-agent-wrote-nothing** (workflow/agent-recovery, NEARS-1749) — `git status --porcelain` is structurally blind to gitignored paths such as `docs/qa-evidence/*`; probe with `--ignored <path>`, `ls`/`find` and an mtime window across the agent's lifetime; absence at the published destination is not absence at the source. (docs/workflow/review-lessons.json)
- **an-enumeration-reads-like-a-measurement** (workflow/evidence-standards, NEARS-1749) — a table with one INFERRED row inherits the credibility of its verified rows; a claim about what a call site PASSES requires tracing the assignment; when proving absence mark each row OBSERVED or INFERRED; three agents sharing a shortcut agree three times and are wrong three times. (docs/workflow/review-lessons.json)
- **device-free-space-is-the-fastest-moving-fact** (workflow/qa-devices, NEARS-1749) — never quote a device free-space figure from a packet or profile; re-measure at acquisition and before scoring; a partial install from space exhaustion presents as the stale-APK class and reads as "the fix did not work". (docs/workflow/review-lessons.json)
- **a-chain-verified-within-one-layer-proves-nothing-about-reachability** (workflow/evidence-standards, NEARS-1749) — every link verified inside one layer proves consistency, not that the chain can be entered; identify which layer produces the entry precondition and verify it THERE; correcting an analysis without leaving the layer raises confidence without raising coverage. (docs/workflow/review-lessons.json)

Shared-ledger rules (`tasks/.atlassian-sync.json` is routinely dirty with other sessions' rows):
- Never `git checkout`, `git restore`, `git stash` or `git reset` on the ledger or any shared file — each restores the last COMMIT and erases every other session's uncommitted rows; undo = the inverse Edit on the exact entry; never round-trip the ledger through a JSON parser. (tasks/workflow-audit-2026-09/findings.json AUD-WF-05 suggested_fix; .claude/commands/new-task.md §[9b] Save the work item 6)
- Stage your own hunks only — `git apply --cached` of your own entries, or `git add tasks/.atlassian-sync.json` when every dirty row is yours; "never `git add -A`"; never stage another run's entries to get your own committed. (.claude/commands/new-task.md §[9b] Save the work item 6; .claude/commands/run-sprint.md §[4] RUN — batch by batch)
- Sprint runs never self-commit the ledger: "NEVER self-commit the ledger" holds for every run inside a `/run-sprint`, even when no sibling entry has landed yet; the runner sweeps and commits from the PRIMARY tree, "staging ONLY that path". (.claude/commands/new-task.md §[9b] Save the work item 6; .claude/commands/run-sprint.md §[4] RUN — batch by batch)
- The ledger is read by grep, never whole: "never Read it whole — Grep the key, Edit that entry"; the same grep-and-edit rule covers language files and every other >30KB file. (.claude/workflow-profile.md §Run artifacts & state; .claude/commands/new-task.md §Guardrails)
